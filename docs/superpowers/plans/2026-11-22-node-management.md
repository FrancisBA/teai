# Idea Node Management Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let people delete, clear, drag, and visually distinguish the typed idea nodes in teai.

**Architecture:** Pure helpers in `resonance.js` handle filtering, movement, and hue derivation; `index.html` wires pointer drag and delete controls to those helpers and persists through `localStorage`. The page stays static and dependency-free.

**Tech Stack:** Vanilla JS, HTML/CSS, Node built-in `node:test`.

**Spec:** `docs/superpowers/specs/2026-11-22-node-management-design.md`

## Global Constraints

- Static serverless page: no build step, no dependencies, no HTTP calls.
- Node positions are viewport fractions in `[0, 1]`.
- Existing storage key `teai.nodes` and the `isValidNode` node shape are unchanged.
- Tests run with `node --test tests/*.test.js`.
- `site/` is generated by `node scripts/sync-site.js` and must mirror the root files.
- Do not commit unless the user explicitly asks.

## Review Focus

- Tapping a node's `×` must delete the node, not begin a drag — pinned by Task 2 `test_delete_control_does_not_start_drag`.
- Drag coordinates outside the viewport or non-finite must stay finite and clamped — pinned by Task 1 `test_move_node_clamps_coordinates_and_keeps_other_nodes` and `test_move_node_uses_current_position_for_non_finite_input`.
- Deleting or moving an id that no longer exists must not throw — pinned by Task 1 `test_remove_node_with_unknown_id_leaves_nodes_unchanged` and `test_move_node_with_unknown_id_leaves_nodes_unchanged`.
- Saved nodes created before this change have no color field and must still get a stable color — pinned by Task 1 `test_node_hue_is_stable_distinct_and_in_range` and Task 2 `test_nodes_use_sequence_hue_custom_property`.
- The hosted `site/` mirror must not drift from the sources — pinned by Task 3's full suite and `node scripts/sync-site.js`.

```js
test('test_remove_node_removes_only_the_matching_id_without_mutating', () => {
  const nodes = [0, 1, 2].map(sequence => TeaiResonance.makeNode({
    text: `idea ${sequence}`, score: 0.5, nowMs: sequence * 1000, sequence
  }))
  const snapshot = nodes.slice()
  const result = TeaiResonance.removeNode(nodes, 'idea-1')
  assert.deepEqual(result.map(node => node.id), ['idea-0', 'idea-2'])
  assert.deepEqual(nodes, snapshot)
})

test('test_remove_node_with_unknown_id_leaves_nodes_unchanged', () => {
  const node = TeaiResonance.makeNode({ text: 'idea', score: 0.5, nowMs: 1000, sequence: 0 })
  assert.deepEqual(TeaiResonance.removeNode([node], 'missing'), [node])
})

test('test_clear_nodes_returns_a_new_empty_array', () => {
  const first = TeaiResonance.clearNodes()
  const second = TeaiResonance.clearNodes()
  assert.deepEqual(first, [])
  assert.notEqual(first, second)
})

test('test_move_node_clamps_coordinates_and_keeps_other_nodes', () => {
  const nodes = [0, 1].map(sequence => TeaiResonance.makeNode({
    text: `idea ${sequence}`, score: 0.5, nowMs: sequence * 1000, sequence
  }))
  const moved = TeaiResonance.moveNode(nodes, 'idea-1', 1.7, -0.4)
  assert.equal(moved[1].x, 1)
  assert.equal(moved[1].y, 0)
  assert.deepEqual(moved[0], nodes[0])
})

test('test_move_node_uses_current_position_for_non_finite_input', () => {
  const node = TeaiResonance.makeNode({ text: 'idea', score: 0.5, nowMs: 1000, sequence: 2 })
  const moved = TeaiResonance.moveNode([node], node.id, NaN, undefined)
  assert.equal(moved[0].x, node.x)
  assert.equal(moved[0].y, node.y)
  assert.ok(Number.isFinite(moved[0].x) && Number.isFinite(moved[0].y))
})

test('test_move_node_with_unknown_id_leaves_nodes_unchanged', () => {
  const node = TeaiResonance.makeNode({ text: 'idea', score: 0.5, nowMs: 1000, sequence: 0 })
  assert.deepEqual(TeaiResonance.moveNode([node], 'missing', 0.2, 0.3), [node])
})

test('test_node_hue_is_stable_distinct_and_in_range', () => {
  const hues = Array.from({ length: 360 }, (_, sequence) => TeaiResonance.nodeHue(sequence))
  assert.ok(hues.every(hue => Number.isInteger(hue) && hue >= 0 && hue < 360))
  assert.equal(new Set(hues).size, 360)
  assert.equal(TeaiResonance.nodeHue(-1), TeaiResonance.nodeHue(359))
})
```

- [ ] **Step 2: Run the tests to verify they fail**

Run: `node --test tests/resonance.test.js`
Expected: FAIL with `TeaiResonance.removeNode is not a function` (and the same for the other three helpers).

- [ ] **Step 3: Implement the four helpers in `resonance.js`**

Define inside the IIFE, before the returned object:
- `nodeHue = sequence => (((Number.isFinite(sequence) ? sequence : 0) * 47) % 360 + 360) % 360`
- `removeNode = (nodes, id) => nodes.filter(node => node.id !== id)`
- `clearNodes = () => []`
- `moveNode = (nodes, id, x, y) => nodes.map(node => node.id === id ? { ...node, x: Number.isFinite(x) ? clamp(x, 0, 1) : node.x, y: Number.isFinite(y) ? clamp(y, 0, 1) : node.y } : node)`

Add all four to the object returned on the final line of the IIFE.
